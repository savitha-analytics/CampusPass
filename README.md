# CampusPass – College Event Registration & Digital Pass Generator

CampusPass is a simple frontend web application designed for college events. 
It allows students to view upcoming events, register for an event, and generate 
a personalized digital event pass instantly.

##  Features

-  View upcoming college events
-  Student event registration
-  Client-side form validation
-  Dynamic digital pass generation
-  Unique ticket ID generation
-  Print digital event pass
-  Responsive user interface

##  Technologies Used

- HTML5
- CSS3
- JavaScript
